Bundled fonts (used by app/core/compose.py for headlines and footers)

  Poppins-Bold.ttf, Poppins-Regular.ttf          Latin text
  NotoSansDevanagari-Variable.ttf                Hindi / Devanagari text

Both families are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org) and may be bundled and used commercially.
To use a different brand font, drop the .ttf here and change the file names
in _font() inside app/core/compose.py.
